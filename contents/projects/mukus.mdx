A Rufus-inspired USB bootable drive creator designed for Linux systems. Built in Python with focus on reliability and ease of use.

## Tech Stack

- Python
- dd/blkid utilities
- GTK/Tkinter (GUI)

## Highlights

- Handles ISO extraction and partition formatting for bootable USB creation
- Supports multiple filesystem types (FAT32, NTFS, ext4)
- Device detection and safe write operations with progress tracking
