Minecraft Beta 1.7.3 ported to C# from the original Java codebase. A deep dive into game engine architecture, block-based world generation, entity systems, and OpenGL rendering pipelines.

## Tech Stack

- C#
- .NET
- OpenGL
- WinForms/SDL

## Highlights

- Ported core game mechanics including terrain generation, block physics, and mob AI
- Implemented chunk-based world rendering with face culling optimizations
- Maintained compatibility with original Beta 1.7.3 gameplay features
