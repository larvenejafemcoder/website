A graphical disk image writer for Linux, wrapping the `dd` utility with a Tkinter-based GUI for user-friendly USB flashing.

## Tech Stack

- Python
- Tkinter
- Linux dd utility

## Highlights

- Detects removable drives and displays device information safely
- Provides write progress visualization and completion status
- Prevents accidental writes to system drives through confirmation dialogs
